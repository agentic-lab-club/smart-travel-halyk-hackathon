## Main product direction

Halyk Travel is a smart travel planner inside a banking ecosystem.

The product should not feel like a chatbot. It should feel like a ready trip plan:
- segmented timeline;
- smart map;
- budget;
- hotel decision support;
- cashback and financial challenges;
- AI-powered labels and summaries.
